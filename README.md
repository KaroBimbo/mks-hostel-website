# МКС Хостел — превью редизайна

Рабочие материалы по обновлению сайта капсульного хостела МКС
(mkshostel.ru, сделан на Тильде). Это не сам сайт, а песочница для
согласования дизайна: правки переносятся в Тильду вручную после того,
как всё утверждено.

## Файлы

- `index.html` — САМ САЙТ (открой в браузере). Это то, что деплоится
  на Vercel: тексты, фото, анимация капсулы на первом экране
- `preview-site-v23.html` — рабочая версия макета с плашкой «превью»
  (из неё собирается index.html)
- `варианты-детализации.html` — черновой перебор степени детализации
  капсулы (архив, финальный вариант уже в превью-сайта.html)
- `дизайн-анимации-главного-экрана.md` — согласованный сценарий
  анимации первого экрана
- `промпты-для-chatgpt.md` — промпты для генерации капсулы в ChatGPT
- `как-снять-капсулу-на-видео.md` — памятка на будущее, если решим
  снять настоящую капсулу на видео вместо рисованной
- `для загрузки на сайт/` — фото, готовые к переносу в Тильду
  (сжаты, названы по-русски)
- `карта мкс.png` — схема прохода от метро до хостела
- остальные файлы — исходные фото хостела (кухня, санузлы, капсулы),
  из них собрано превью
